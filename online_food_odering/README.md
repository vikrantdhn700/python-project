# Online Food Ordering System

A dependency-free Python console program demonstrating object-oriented
programming with `Restaurant`, `FoodItem`, `Customer`, and `Order` classes. Each
class is defined in its own module and imported by the main program.

## Run

```powershell
python main.py
```

The demonstration creates five menu items and displays complete summaries for
two customer orders, including quantities, line totals, and the total bill.
